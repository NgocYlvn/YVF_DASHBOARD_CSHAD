# YVF Adoption Dashboard – CS HAD

## Files
- `app.py`: Streamlit dashboard
- `YVF_Adoption_Data.xlsx`: source workbook
- `requirements.txt`: Python packages

## Deploy on Streamlit Community Cloud
1. Upload all three files to the same GitHub repository.
2. In Streamlit Community Cloud, select the repository.
3. Main file path: `app.py`
4. Click **Deploy**.

To update data later, replace `YVF_Adoption_Data.xlsx` in GitHub with the latest workbook while keeping the same filename.
